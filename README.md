## ✨ What is Lofi PLAYBOOK?

<div align="center">

| 🌙 | 🎵 | 🌧️ | 💜 |
|:---:|:---:|:---:|:---:|
| **Midnight** | **Slowed + Reverb** | **Rainy Vibes** | **Hindi Lofi** |

</div>

**Lofi PLAYBOOK is a midnight lofi music hub — slowed + reverb Hindi songs, made for rainy nights, late-night study, and calm.**

Listen to **"Tu Online Hai"**, **"Raaton Mein Tu"**, **"Agar Tum Saath Ho"**, **"O Romeo"** and **"Dil Ke Kone Mein"** — with a live premiere countdown, an interactive audio player, and a creator portfolio showcase.

> 🎧 **No login needed to listen.**
> Open the site, pick a song, and it takes you to YouTube to listen there.

```mermaid
Open lofiplaybook.xyz → Pick a song → Listen on YouTube → Follow the countdown
```

## 🚀 Deploy to GitHub Pages

| Step | What to do |
|:---:|---|
| **1** | 📤 Upload **all files and folders** (`index.html`, `login.html`, `sw.js`, `updates.json`, `push-server/`, `CNAME`, `README.md`) to this repo |
| **2** | ⚙️ Repo → **Settings → Pages** → Source: **Deploy from a branch** → Branch: `main` → Folder: `/ (root)` → **Save** |
| **3** | 🌐 Custom domain is already set via the `CNAME` file — `lofiplaybook.xyz` |
| **4** | 🔒 Tick **Enforce HTTPS** |
